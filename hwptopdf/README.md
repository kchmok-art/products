# HWP to PDF 변환기

한글(HWP) 파일을 PDF로 변환하는 독립 실행 프로그램입니다.

## 📥 다운로드

실행 파일은 저장소가 아니라 [Releases](https://github.com/kchmok-art/products/releases/latest)에서 받습니다.

- [hwptopdf-windows.zip](https://github.com/kchmok-art/products/releases/latest/download/hwptopdf-windows.zip) — `hwptopdf.exe`, `실행.bat` 포함

## 📋 시스템 요구사항

- **운영체제**: Windows 7 이상
- **한글 프로그램**: 한글과컴퓨터 한글 2010 이상이 설치되어 있어야 합니다
- **Python**: 설치할 필요 없음 (독립 실행 파일)

## 🚀 사용 방법

1. 위 링크에서 zip 파일을 받아 압축을 풉니다
2. **hwptopdf.exe** (또는 **실행.bat**) 파일을 더블클릭하여 실행
3. 파일 선택 다이얼로그에서 변환할 HWP 파일들을 선택
4. 자동으로 PDF 파일로 변환됩니다

## 📁 변환 결과

- 변환된 PDF 파일은 원본 HWP 파일과 같은 폴더에 저장됩니다
- 파일명은 원본과 동일하되 확장자만 `.pdf`로 변경됩니다

## ⚠️ 주의사항

- 한글 프로그램이 설치되어 있지 않으면 변환할 수 없습니다
- 변환 중에는 한글 프로그램이 백그라운드에서 실행됩니다
- 대용량 파일의 경우 변환 시간이 오래 걸릴 수 있습니다

## 🔧 문제 해결

### "한글 프로그램 실행 오류" 메시지가 나타나는 경우
- 한글과컴퓨터 한글 프로그램이 설치되어 있는지 확인
- 한글 프로그램을 한 번 실행해본 후 다시 시도

### 변환이 실패하는 경우
- HWP 파일이 손상되지 않았는지 확인
- 파일이 다른 프로그램에서 열려있지 않은지 확인
- 관리자 권한으로 실행해보기

2. HWP 파일의 무결성
3. 파일 권한 설정
